## 제1장. 이 책을 읽는 법과 오늘 패치

**핵심: 설명, 게임 수치, 추천, 미확인을 서로 바꿔 읽지 않는다.**

### 1-1. 근거 표시

|표시|뜻|사용할 때 지킬 조건|
|---|---|---|
|[확정·사용자]|사용자가 직접 확정·정정한 내용|확정한 범위만 적용한다. 다른 병종·효과로 넓히지 않는다.|
|[확정·표기]|영상 툴팁·인게임 화면에서 읽은 내용|문구를 읽은 것과 실제 발동을 검증한 것을 구별한다.|
|[자료 채택]|사용자가 채택한 보관 사이트 자료|사이트에 적혀 있다는 근거이며 독립적인 인게임 실험은 아니다.|
|[실측]|조건과 시점이 있는 관측|병력·장비·버전·시간축을 함께 보존한다.|
|[계산]|명시한 전제로 얻은 산술 결과|전제가 틀리면 다시 계산한다.|
|[강한 추론]|관측과 잘 맞지만 다른 설명이 남음|성공 가능성을 설명하되 보장하지 않는다.|
|[작성자 평가]|등급·추천·경험적 운용|게임의 수치 규칙이나 실전 최소 컷으로 사용하지 않는다.|
|[미확인]|분모·시점·중첩·범위 등이 특정되지 않음|빈칸을 추측으로 채우지 않는다.|

같은 대상·효과·시점에 대한 명시적 최신 사용자 정정을 우선한다. 패치 전 영상은 당시 버전의 증거로 유지한다. 서로 다른 조건의 값을 단순한 최신순으로 덮어쓰지 않는다. 원문과 실험이 충돌하면 양쪽의 조건을 남긴다.

### 1-2. 용어를 바꾸지 않는 원칙

‘현재 HP’와 ‘최대 HP’, ‘공격력 증가’와 ‘주는 피해 증가’, ‘추가 피해’와 ‘추가 고정 피해’, ‘자신’과 ‘자신의 군대’는 서로 다른 말이다. 쉬운 설명에서도 교환해 쓰지 않는다. ‘영웅 본체 능력’과 ‘고유 고급 재능’도 별개의 효과다.

도감에 남아 있는 표기·띄어쓰기·부호는 임의 교정하지 않는다. 별칭은 검색을 돕는 대응표에만 둔다. 예를 들어 `맥도`를 임의로 다른 무기명으로 바꾸거나 `회피률` 원문을 고쳐 인용하지 않는다.

|---|---|
|HP / 최대 HP / 현재 HP|체력 / 체력의 상한 / 지금 남은 체력|
|개체 / 부대|병사·영웅·보스 한 명 / 함께 편성한 병력 묶음. 부대 수와 개체 수를 바꾸어 세지 않음|
|DPS|초당 피해. 실제 공격할 수 있는 시간과 타격 간격에 따라 달라짐|

|피해 패킷|한 번의 독립된 피해 처리. 한 공격 안에서도 일반 피해와 추가 고정 피해가 따로 처리될 수 있음|
|BEP|손익분기점. 어떤 자원의 수입과 비용을 비교하는지 먼저 정함|
|max / floor / ceil|큰 값 선택 / 소수점 아래 버림 / 소수점 아래 올림|

|기존 대화·계산기 별칭|같이 검색할 기존 표기|주의|
|---|---|---|
|칼방|병사(칼&방패), 칼과 방패|검&방패와 다른 병종|

|검기병 / 창기병 / 대도기병 / 궁기병|기병(검) / 기병(창) / 기병(대도) / 기병(활)|별칭과 원문을 함께 보존|
|sns / lb / imp / hcav / bcav|검방 / 장궁 / 강화 쇠뇌 / 중기병 / 궁기병|보관 공략의 용어 대응|
|modao / dagger-axe / nail|맥도 / 장과 / 고정기|게임 규칙이 아닌 용어 대응|

### 1-3. 오늘 패치의 현행 수치

근거는 사용자가 제공한 공지다. 서버별 시행 시각을 따로 확인한 자료는 아니다. 아래 변경만 과거 문구를 대체하며, 공지에 없는 효과를 함께 바꾸지 않는다.

|항목|새 기준|적용|
|---|---|---|
|장검 기본HP Lv1~6|208/258/320/397/492/610|현행 통합 마스터,계산기데이터·생존계산|
|도끼&방패 기본공격 Lv1~6|10/14/18/22/26/30|현행 통합 마스터,계산기데이터·공격계산|

## 공지에 없는 수치를 만들지 않은 부분

- [확정·사용자 후속 설명] 대도 찍기 계수는 Lv.1~6에서 20/22/24/26/28/30%다. 레벨당2%포인트 증가한다. 이전의 중간 레벨 미공개·범위 끝값 가정은 대체한다.
- 대상변경시찍기기본중첩을초기화하되,기존언월도50%비축/이전효과는미구현임을별도로표시한다. 그효과가삭제됐다고가정하지않는다.
- 화궁추가발동의범위·순환방지·연쇄횟수상한·20%합/곱누적을임의로정하지않는다.
- 중기병의추가기절을기존기절과무조건합쳐총2턴이라고쓰지않는다.
- 초급보류를확정0.4분노로바꿔기술문턱을계산하지않는다. 고유재능2보유·중급최대분노-1·쌍도끼확률은이번일괄40%대상이아니다.
- 열병대새확률·보장횟수·새상품가격을모르므로과거1.374병부/회등기대공급량과25만/35만원견적을재사용하지않는다.

## 코칭에 미치는 변화

1. **장검:** 기본HP는약17.5~17.9%증가하지만무기·영웅고정HP를합친최종증가율은더작을수있다. 고정수치공격에는생존여유가늘지만대상최대HP비례피해에는피해절대량도함께늘어난다. ‘생존시간모두18%증가’로환산하지않는다. 최대HP비례회복·보호막도함께재계산한다.
2. **도끼방패:** 기본공격증가는Lv1약11.1%,Lv6 25%다. 공격력계수형일반·스킬·회복/흡혈의실제기여는각효과기준에따른다. 적최대HP비례독립피해까지같이25%오른다고쓰지않는다.
3. **대도:** 범위최솟값15→20은상향,최댓값40→30은하향이다. 병종전체를일률상향/하향으로분류하지않는다. 같은대상유지시간·찍기횟수·대상변경이중요하다.
4. **분노재능:** 확정회전단축에서확률회전단축으로바뀌었다. 무손실보수판단에서이재능의발동을필수생존근거로쓰지않는다. 평균기여와첫기술실패위험을분리한다.
5. **화궁·육손:** 확산확률감소와화염연쇄보상이동시에있다. 두효과를상쇄한다고임의계산하지않는다. 불의배치·대상체류·아군화염네트워크가핵심변수다.
6. **포인트·과금:** 하루50회복이라는유량과보유량상한은다르다. 누적보유량을입력상태로두며,상자기대값·소집기대값은새규칙과구분한다.

### 1-4. 패치의 정확한 원문과 미공개 구간

- 육손: “불화살을 발사한 후, 아군 땅에 있는 불이 [15-30]% 확률로 적군 방향으로 1칸 확산된다.”
- 기병(대도): “대상을 찍어 공격력의 [20-30]%에 해당하는 추가 고정 피해를 입힌다. 같은 대상에게 찍기를 시전하면 추가 고정 피해가 중첩되며, 대상을 변경할 때까지 유지된다.”
- 화궁 요원: “화염 발동 시 추가로 주변 아군의 화염을 추가 발동시킨다. 1회 추가 발동될 때마다 해당 회차의 화염 피해가 20% 증가한다.”
- 중기병 충돌: “부딪친 최대 4명의 대상을 1턴 동안 추가로 기절시킨다.”
- 초급 재능: “스킬 시전 후 40% 확률로 분노치 1 보류”. 고유 재능의 분노2 보유와 중급 최대 분노-1을 이 문구로 바꾸지 않는다.

[확정·사용자 후속 설명] 대도 찍기는 레벨당2%포인트 증가하여 Lv.1~6이 **20/22/24/26/28/30%**다. 이는 추측 보간이 아니라 사용자가 직접 확정한 값이다. 기존의 중간 레벨 미공개 표기와20/30% 범위 끝값 가정은 폐기한다. 화염 연쇄의 범위·재연쇄·증폭 합산 방식과 중기병 총 기절 시간은 별도 미확인이다.
