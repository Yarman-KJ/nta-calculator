## 4. 파밍·성장·공타 기준

### 4-1. 파밍은 반복 운영을 기준으로 평가

초소를 한 번 무손실로 미는 것과 연속으로 미는 것은 다르다. 사용자는 초소를 계속 밀어야 하므로 회복수단이 필수라고 명시했다. 전투 종료 HP, 다음 전투 전 회복, 반복할 때 누적되는 손실까지 기록한다. 1회성 구리 방패와 매 턴 회복하는 술 조롱박을 같은 지속 회복으로 취급하지 않는다.

주력 병종은 전용무기 옵션과 주변 3·5레벨 보스 장비를 확인하고 정한다. 쇠뇌차 + 탱커의 초기 파밍, 대장간 14레벨 관통 강화, 보스 반사 장비 위험, 난이도·거리·손실 기준은 기본편 원문과 기존 제5·8장을 함께 적용한다. 예시 5부대 편성은 보장 클리어 조건이나 최소 컷이 아니다. 지옥2 4부대 전사 0 성공과 별도 5부대 성공을 각각 보존한다.

사용자 초보자 목표: 첫날 거점14·대장간14·영지100개 이상·팀 대사관8, 둘째날 거점18·두 번째 전용무기·팀 대사관13, 셋째날 거점20·6레벨 병력 확보·전무 임시 제련·안전 확보 전 영지190 이하 유지. 이는 운영 목표이며 모든 판의 확정 자원 보장은 아니다. 기본편의 ‘안전하지 않다면 봄~여름 200을 넘기지 말 것’과 190 관리 목표는 여유를 둔 운용 기준으로 함께 보존한다.

보상포인트는 사용자 제공 패치의 매일50 고정 회복·상한 삭제를 적용한다. 건설자원·총자원·특수보상·포인트 소비를 혼합하지 않는다. 둔전 9포인트와 황금상자7~10개, 5회45포인트 후 남은5포인트의 Lv2 활용은 해당 사용자 사례 조건이다. 상자 수를 보상포인트로 바꾸거나 특수보상이 있는 점령과 동일시하지 않는다.

### 4-2. 전장 이동과 연결 유지

공타는 방향·투입 순서를 설계하고, 수타는 분산 배치되어 통제가 어렵다는 기본편 구분을 유지한다. 유리한 공타의 연결 타일을 지키고, 보호타일·요새·후속 합류를 미리 준비한다. 연결 차단에 따른 강제 회군, 회군 위치 유도, 레이저로 진입 자리를 채워 회군 위치를 바꾸는 응용은 조건과 함께 전투편 원문에 보존한다.

일반 야생지 5부대와 거점 10부대 제한을 혼동하지 않는다. 더미를 한 기씩 투입해 불필요한 이동을 유도하는 전술과 병종 공속의 수치 계산을 혼합하지 않는다. 보호타일 7시간·계절 예외·거점 주변 예외는 기본편의 적용 조건을 확인한다.

### 4-3. 공타 시간은 고정 DPS 하나로 일반화하지 않음

실측 보고서의 기준은 Lv20 초소 초기 HP135다. 최초~마지막 피해 표시 경과시간과 리플레이 전체 길이를 구분하며 정책 영상의 일시정지16.600초는 보정한다. 표시 피해136은 마지막 초과피해1로 설명될 수 있으므로 초기 HP를136으로 바꾸지 않는다.

|실측 편제|마지막 피해 표시 51초 전 재구성 HP|49초 전 재구성 HP|
|---|---:|---:|
|중기병 + 30% 공성의 달인|49|46|
|망치&방패 + 투석차|78|75|
|중기병 + 대도기병|38|37|
|창&방패 + 화궁|32|31|

이 표는 해당 영상의 사후 재구성이다. 다음 판의 보장 출발 HP가 아니다. 실전50~52라는 사용자 관측도 삭제하지 않는다. 전투편의 `초소 피 = 이동시간 × 0.7` 등은 급할 때의 경험적 근사로 보존하며, 모든 편제·정책에 적용되는 확정식으로 사용하지 않는다. 지도 소유권 전환에 필요한 실제 지연은 영상의 마지막 피해 표시만으로 확정되지 않는다.
