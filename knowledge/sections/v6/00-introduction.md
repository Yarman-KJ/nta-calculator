기준일: 2026-10-21. 이 파일의 목적은 대화가 없어도 게임 지식, 사용자의 판단 기준, 수치의 조건, 근거와 미확인 사항을 복원하는 것이다.

## 읽는 순서와 적용 우선순위

1. **현행기준:** 이번 보강장의 사용자 확정·정정과 적용 범위를 먼저 읽는다.
2. **상세 지식:** 뒤에 원문 그대로 수록한 기존 통합 마스터에서 병종·영웅·장비·정책 수치와 이동·파밍·전투 규칙을 찾는다.
3. **조건과 근거:** 사용자 제공 추천 통합안, 기본편·전투편, 공타 실측 보고서를 함께 읽는다. 원문에 남은 과거 설명은 아래 충돌표와 대조한다.
4. **원문 복원:** 보존 묶음의 대화 원문·자료 사본·파일 목록을 사용한다. 대화 링크만을 유일한 근거로 남기지 않는다.

최신 사용자 정정은 같은 대상·조건·버전에 한해 우선한다. 사용자가 붙여 넣은 AI 분석 전체를 자동으로 사용자 실측 확정으로 승격하지 않는다. 사용자 추천, 도감 문구, 영상 실측, 계산기 가정, AI의 추론은 구분한다. 기존 문장을 삭제하거나 용어를 임의로 교체하지 않고, 정정의 적용 범위를 이 장에서 지정한다.
