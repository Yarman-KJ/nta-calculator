## 제15장. 계산기 범위·분석 방법·추가 자료

**핵심: 계산기의 통과와 실제 게임의 무손실을 구분한다.**

### 15-1. 현재 사이트·계산기의 기능과 한계

현 작업본은 병종별 장비 추천·보스·공타3개 탭, 한국어·번체 중국어, 개인 추천 기준 편집·JSON 백업을 제공한다. 장비 추천은 작성자 관계표와 현재 후보를 이용하며 전투 레벨·상대 조건을 완전히 받아 최적화하는 기능은 아니다.

현재 사용자 기준은 제13장 표를 따른다. 코어6·추천3·쓸만함1이라는 점수는 후보 자동 채움용이며 실제 피해 배율이 아니다. 후보는 최대8개, 최종 구성은 랜덤2·제련2다. 사거리2~3 병종의 유성추 필수는 사용자 추천 제약이며 모든 게임 상황의 절대 규칙이 아니다. 독궁·사냥꾼·도끼방패는 자동 추천을 비우고 직접4옵션 구성을 허용한다.

일반 기병의 별도 ‘두더지’ 분류는 중기병·궁기병에 적용하지 않는다. 궁병 및 궁기병·맥도·장과·긴 창의 방어 장비 자동 추천 제외도 현재 작업본의 사용자 기준이며 그 병종이 해당 장비를 장착할 수 없다는 규칙이 아니다. 구체적인 제외 목록은 아래에 보존한다.

|범위|자동 추천 제외 장비|
|---|---|
|병과: 궁병; 병종: 궁기병; 병종: 맥도; 병종: 장과; 병종: 긴 창|술 조롱박, 정심회, 덩굴 방패, 사슬갑옷, 구리 방패, 황월, 무쇠 방패, 흑요석 갑옷, 피해 반사 갑옷, 군기, 태양 갑옷, 금 사슬갑옷, 호심경, 옥패, 분노의 허리띠, 회피 신발, 현목 영락, 명광 갑옷, 적금순|

보스 계산은 두 병종·병기·최대4명 영웅, 병사·병기45개체 이내 탐색이다. 영웅 수와 장비를 고정하고 작은 병력 조합부터 검사한다. 영웅의 본체 능력과 재능을 자동으로 완전 적용하지 않는다.

손실 모델은 대표 개체 집중 피격과 순차 교체, 후열 노출 비율을 사용한다. 실제 격자 이동·최근접 무작위·개체별 광역 분산을 구현한 엔진이 아니다. 패치 데이터와 대도의 개체/대상별 중첩은 반영됐지만 화염 공간 연쇄·중기병 경로와4명 기절·초급 분노 재능의 전체 확률 경로는 미구현이다.

현재 코드의 피해식·혈적자 처형 시점·현재 HP 추가 피해 계수에는 원장과 충돌이 남는다. 모델의 실패로 실제 영웅 단독 클리어를 부정하거나 통과를 실전 보장으로 제시하지 않는다. 옵션별 최소값은 다른 값을 고정한 단일 변화 결과이므로 각 최솟값을 동시에 적용하면 실패할 수 있다.

개인 추천 편집은 현재 브라우저·주소에 저장된다. 내보내기는 백업, 불러오기는 개인 기준 전체 교체다. 다른 채팅·다른 기기·공개 사이트 공통 기준이 자동 갱신되는 기능은 아니다.

### 15-2. 답변·코칭 절차

1. 사용자 목적과 이미 제공된 조건을 확인한다. 가능한 풀·해금·슬롯·보유 장비를 먼저 고정한다.
2. 현행 버전의 개체 스탯·영웅 범위·장비 조건을 이 파일에서 찾는다.
3. 이동→공격 기회→타깃→피해별 계산→분노→회복·생존→보고서의 순서로 설명한다. 이 순서는 분석 절차이며 미확인 게임 내부 처리순서를 확정한 것이 아니다.
4. 알려진 규칙과 후보가 갈리는 지점을 분리한다. 후보가 바뀌어도 추천이 같은지 검사한다.
5. 핵심 판단·현재 바꿀 행동·적용 규칙을 먼저 말하고 V번호·시점·조건을 근거로 연결한다.
6. 자료 부족이 결론을 바꿀 때만 아래 형식처럼3줄로 요청한다. 이미 제공된 자료부터 재사용한다.

각 개체의 현재/최대 HP, 보호막·이월 피해, 분노, 위치·타깃, 버프 잔여기간과 중첩, 최초 발동 사용 여부를 분리한다. 부대의 평균 HP 하나로 모든 효과를 대신하지 않는다.

### 15-3. 필요한 자료 요청 —3줄

1. **피해식:** 계수100%가 아닌 동일 스킬의 피해 증가 전후 숫자와 당시 공격력·대상 방어 조건이 필요하다. 기존 판독 가능한 장면부터 사용한다.
2. **손실 HP:** 회복 직전·직후 HP와 이어지는 공격 피해가 함께 보이는 짧은 구간이 필요하다. 갱신 시점이 추천을 바꿀 때만 추가 요청한다.
3. **현행 대도:** Lv.2~5 찍기 계수의 게임 내 표기가 필요하다. 확인 전20~30% 범위를 유지하며 보간하지 않는다.

이3개는 통합본 사용을 막는 필수 제출물이 아니다. 현재 미확인인 규칙을 확정할 때 필요한 최소 근거다. 새 소집 확률·보장 횟수·상품 가격은 성장 구매 계산을 다시 요청받을 때만 확인한다.

### 15-4. 통합 품질과 게임 예측의 검증을 구분

자료·숫자·적용 범위 보존, 코드 일관성, 실제 게임 규칙 검증, 처음 보는 전투 예측은 각각 다른 검사다. 이번 통합의 검사 결과는 통합검증 폴더에 둔다. 통합 문서가 더 읽기 쉽고 정합적이라는 것과 아직 모르는 규칙까지 알아냈다는 것은 다르다.
