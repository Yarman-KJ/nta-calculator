## 관리 방법

원문 조각을 직접 수정하지 않습니다. 새 분석과 판정은 현행 데이터·근거 기록에 별도로 반영합니다. 새 원문이 생기면 기존 V6를 덮어쓰지 말고 별도 버전으로 보존합니다. `node tools/split-knowledge.cjs --check`로 원문과 분리본을 검사합니다. `manifest.json`에 각 파일의 범위와 해시가 있습니다.
