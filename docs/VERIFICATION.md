## 조사 결과와 변경

기존 원격 저장소에는 단일 `index.html`, 이미지, 공략 HTML만 있었다. 개발용 JavaScript·자동 테스트·CI는 없었다. 로컬 프로젝트 자료의 10개 JavaScript를 배포본의 10개 인라인 스크립트와 전수 비교해 내용이 일치함을 확인한 뒤 복원했다. 실행 데이터만 `data/current/`로 분리하고 나머지는 `src/`에 두었다. 기존 이미지와 공략, 공개 HTML은 변경하지 않았다.

첨부 V6를 바이트 그대로 `references/`에 보존하고 SHA-256과 크기를 기록했다. 원본 프로젝트의 `sources/`는 수정하지 않았다. 공통 지침·패치 절차를 문서화하고 대표 근거 5건을 네 분류로 분리했다. 이 작업은 V6의 모든 지식을 구조화하거나 실행 데이터에 반영하는 전수 이관이 아니다.

## 남은 이슈

## 후속 작업: V6 주제별 분리

2026-10-23, V6 원문 826,355바이트 전체를 `knowledge/sections/` 아래 51개 파일로 분리했다. V6 보강 8개, 통합 마스터 18개, 버전 차이를 보존한 과거 동기화 소스 18개, 원문 부록 6개, 복원 위치 1개다. `knowledge/README.md`는 주제별 읽기 경로이며 `knowledge/manifest.json`은 원문 행·바이트 범위와 파일별 해시를 기록한다. 본문을 요약하거나 중복·과거 내용을 삭제하지 않았다.

추가 테스트는 51개 파일의 전체 원문 재조립, 누락·중복·변조 탐지, 색인 재생성 일치를 확인했다. 기존 테스트 6개와 원문 보존 테스트도 모두 통과했다. `index.html` 재생성 일치 검사도 통과했다. 원문과 실행 데이터·공략·이미지는 수정하지 않았다. 공통 지침은 전체 V6를 매번 읽는 대신 주제 색인에서 보강·충돌표·필요한 본문을 선택하도록 갱신했다.

원문에 포함된 상대 경로·문서 내부 링크는 원문 그대로이므로 분리본에서 모두 열리는 것은 아니다. 분리본 찾아보기 또는 보존 원문으로 이동해 확인하며, 누락된 외부 자료를 있다고 가정하지 않는다. 이번 작업은 원문 전체의 주제별 분리이며 게임 규칙의 전수 검증·현행 실행 데이터와의 전수 대조는 여전히 남아 있다. 공개 사이트에 분할 게시하지 않았다.

## 남은 검증 범위

- 후속 분리 작업 업로드 후 `main`이 `26e6b48`까지 별도 개편된 것을 확인했다. GitHub는 README 충돌을 표시한다. 이 브랜치의 개발 소스와 테스트는 최초 기준 `7d482fd`를 대상으로 하며 새 사이트에 대한 동기화·통합 검증이 필요하다. 이 이슈를 해결하기 전에는 병합 준비 완료로 보지 않는다. 이번 분리 커밋에 대한 원격 CI 성공은 확인하지 않았다.

- 게임 내 실측은 하지 않았다. 테스트에 ‘확정’이라는 기존 표현이 있어도 게임 규칙을 새로 검증했다는 뜻은 아니다.
- 기존 데이터 전체와 V6의 대응·충돌은 추가 감사가 필요하다. 대표 근거 5건만 분류했고 미확인 튕김 판정은 유지했다.
- 기존 `test.cjs`는 현재 배포하지 않는 구형 상세 계산기의 코드 대상이라 이번 복원에서 제외했다.
- 브라우저 육안·모바일 확인과 외부 이미지 접속 확인은 미실행이다.
- CI 워크플로는 추가했으며 원격 실행 결과는 별도로 확인해야 한다.
- 공개 배포와 기본 브랜치 병합은 수행하지 않는다. 검토용 브랜치에서만 변경을 제안한다.
- 원격 push는 처음 자동 승인 검토에서 차단됐으나, 이후 사용자가 검토용 브랜치 push와 초안 PR 생성을 명시적으로 승인했다. 승인 후 브랜치를 원격에 올렸다. 기본 브랜치 병합과 사이트 배포는 승인 범위에 포함되지 않는다. 원격 CI 결과는 PR에서 별도로 확인한다.
